## Reporting a Vulnerability

**Please do not file a public ticket** mentioning the vulnerability.

This repository has no private vulnerability reporting channel yet. Until one is published here, do not disclose a vulnerability in any public channel. Please read the [disclosure page](https://github.com/sila-chain/go-sila/security/advisories?state=published) for more information about publicly disclosed security vulnerabilities.
